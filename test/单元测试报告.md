## 4. 关键断言说明

本次测试不是只判断程序是否报错，而是对关键业务结果做了明确断言：

- 认证：断言注册写入参数、默认金币、默认收藏夹、返回字段不包含密码、登录 token 格式、管理员密钥校验、异常类型。
- 验证码：断言生成 id 格式、SVG data URL、验证码大小写不敏感、校验后立即失效、过期记录返回 false。
- 邮箱验证码：断言邮箱大小写/空格归一化、验证码只可使用一次、过期验证码失效、单邮箱最多保留最近 5 个验证码、SMTP 配置不完整时兜底 mock 发送。
- 存储：断言 MinIO Client 调用次数和参数、本地文件真实写入/复制/删除、初始化失败后切换 local 模式。
- 搜索发现：断言视频/用户/直播搜索分支、分页上限、分类解析、热门推荐、热词去重、空关键词建议返回空列表。
- 视频：断言观看时长上限、完播规则、分类去重和默认分类、分页边界、排序规则、搜索关键词分词、推荐/搜索评分相对大小。
- 媒体代理：断言只允许 http/https，且只能访问白名单媒体主机，只复制媒体相关响应头。
- 动态流：断言 feed item 的 id、type、author、cover、stats、score 规则，以及响应前移除内部 score。
- 关注：断言不能关注自己、关注关系 upsert 参数、通知类型、取关结果、关注状态、趋势日期格式。
- 私信：断言隐私规则 `DISABLED`、`FOLLOWING_ONLY`、给自己发信、空内容、超长内容、目标用户不存在、消息内容 trim。
- 用户：断言主页统计、分类回退、非本人隐藏金币、本人显示金币、资料更新过滤 `undefined`、邮箱重复阻断。
- 举报：断言举报原因 trim、不同举报目标写入不同字段、目标不存在时抛出 `NotFoundException`。
- 管理审核：断言非管理员被拒绝、视频审核通过变为 `PUBLISHED`、驳回写入原因、文本治理状态更新、举报处置记录操作者。
- 直播/礼物：断言直播间状态流转、非主播禁止操作、非开播不能加入观众、聊天内容截断/空内容拒绝、录播保存为视频草稿、钱包和签到奖励规则。
- 公共工具：断言统一响应结构、分类映射一致性、瞬断数据库错误识别、空搜索返回空结果。


## 5. 流水线阻断说明

流水线应在构建镜像、推送镜像、部署之前执行：

```bash
node test/run-unit-tests.js
```

`test/run-unit-tests.js` 会自动收集并执行 `test/unit/*.test.js`。只要任意测试断言失败，Node 测试进程会返回非 0 退出码，`run-unit-tests.js` 也会把该退出码向外传递。因此 CI/CD 流水线会停止，不能继续发布镜像或部署。

本次补测过程中曾出现过断言失败，命令退出码为 1，说明该入口确实可以在测试失败时阻断后续流程。修正断言后最终结果为 97/97 通过。
