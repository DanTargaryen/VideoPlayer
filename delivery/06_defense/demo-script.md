## 0:00–0:35 开场与架构

默认负责人：A / 林明。

- 打开 PPT 第 1–3 页。
- 一句话说明：单体 tag 可回归；Gateway 后是 identity、content、live、governance 四个独立 owner 服务。
- 展示当前环境的 Gateway `/version` 和四服务 `/health/ready`，确认演示不是静态截图。

失败 fallback：若某个探针异常，立即切到已保存的 CI/Kind evidence 与备用录屏相同时间点，不现场重建镜像。

## 0:35–1:20 UC01 登录、资料与推荐

默认负责人：B / 刘钟屹；C / 李晓萌配合推荐与详情说明。

1. 使用演示普通账号登录。
2. 修改一个无敏感信息的昵称或简介。
3. 回到首页，打开推荐与视频详情。
4. 在 Network 或日志中指出请求经 Gateway，并带有 requestId/upstream。

验收点：登录成功、资料可读回、推荐与详情 200；未暴露数据库/Token。

## 1:20–2:20 UC03 投稿、审核与发布

默认负责人：C / 李晓萌；E / 王一涵配合治理审核说明。

1. 使用已准备的短 MP4 上传，展示 MIME/ffprobe 通过和 MinIO 资产。
2. 保存草稿并提交审核。
3. 切到管理端，打开待审快照并通过。
4. 回到创作中心，展示状态变为已发布与 review history。

验收点：content 保存资产/稿件，governance 保存审核，决定写回 content；重复 requestId 不重复创建。

失败 fallback：上传受限时使用预先准备的待审稿件，从管理端审核步骤继续，并在讲解中明确“上传现场未执行”。

## 2:20–3:05 UC04 互动与通知

默认负责人：C / 李晓萌负责内容互动，B / 刘钟屹负责 identity 通知侧。

1. 切换到另一个演示用户，对已发布视频评论、点赞和收藏。
2. 返回创作者账号，打开通知中心。
3. 展示评论/点赞/收藏至少一条通知。

验收点：主体写入与计数事务完成；Outbox 最终为 DELIVERED；通知失败不会回滚主体。

## 3:05–4:25 UC05 直播、消息与录播

默认负责人：D / 张壮志。

1. 主播创建房间并开播；观众加入。
2. 发送一条弹幕/聊天，展示 viewer count 或消息快照。
3. 完成一次投币，展示钱包和账本变化。
4. 停播并登记已准备的录播资产；展示 Session=ENDED 与录播稿件 ID。

验收点：房间、Session、ViewerEvent、Message、CoinTransaction 和 ReplayRegistration 持久化；服务重启后关键数据可读。

失败 fallback：摄像头/麦克风权限或 SRS 异常时，切换兼容帧模式或备用录屏；不要临时修改浏览器安全配置。

## 4:25–5:10 UC06 举报、处置与审计

默认负责人：E / 王一涵。

1. 普通用户举报已准备的视频或评论。
2. 管理端打开举报并执行 `KEEP` 或 `DELETE/HIDE`。
3. 展示同一记录不可重复处理、审计决定和举报人通知。

验收点：governance 不直查 content 表；目标状态通过 contract 应用；补偿状态可审计。

## 5:10–6:15 工程证据

默认负责人：A / 林明讲 CI/K8s/HPA/性能，E / 王一涵讲 REG-01 与证据追溯。

- PPT 第 4、6–9 页：REG 单体 6/6 + Gateway 6/6；最终 `test:ci`；远端 3/3 jobs。
- HPA：解释 Ready Pods 1→3→2→1 和 CPU 104%→2%。
- 故障：MySQL readiness 503→200、SRS start 503→200/ENDED、MinIO upload 500→200。
- 性能：单体/Gateway 中位 p95 9.44/15.57 ms，1440 请求 0 error。

不要口头把微服务吞吐下降说成“性能提升”；结论应是“开销可测、错误为零、延迟仍低，换取独立 owner、部署与恢复边界”。

## 6:15–7:00 回滚与收尾

默认负责人：A / 林明负责 rollback，E / 王一涵负责 DEL-01 证据边界与结论。

1. 展示 Gateway 当前 cutover allowlist。
2. 说明或在预备环境执行 `GATEWAY_ROUTE_MODE=monolith` 回滚探针。
3. 强调单体 owner 表仍保留，迁移逐表比较，失败不删除数据。
4. 打开 PPT 第 10 页收尾：交付是一条可运行、可回归、可部署、可恢复的证据链。

## 现场问答准备

- 为什么不删除单体表？——课程期内回滚与比较优先，删除是另一个需要生产授权的不可逆 Gate。
- 如何避免重复写？——requestId + payload hash Receipt、数据库唯一键、事务和冲突 409。
- 服务挂了怎么办？——能力级 fallback/rollback、Outbox/补偿、依赖 readiness 与恢复探针。
- 微服务是否更快？——本实验不是“更快”，而是量化了开销；架构收益是边界、独立部署、弹性和故障隔离。
- AI 是否真实调用？——外部付费 AI 未作为自动 Gate；最终治理 contract、人工处置和补偿是可重复验证的。
