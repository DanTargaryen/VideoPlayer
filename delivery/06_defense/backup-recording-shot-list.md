# 5–8 分钟备用录屏拍摄清单

> 状态：`PLAN READY / RECORDING NOT PROVIDED`。勾选只能由实际录制人完成。

## 录制前

- [ ] 确定录制人、讲解人、操作者和最终 commit。
- [ ] 使用隔离演示账号/数据库，清除私人数据和历史通知。
- [ ] 关闭邮件、聊天、系统通知、浏览器收藏栏和密码自动填充提示。
- [ ] 检查屏幕中没有 `.env`、Token、数据库口令、MinIO Secret 或私人路径。
- [ ] 前端、Gateway、四服务、四数据库、MinIO、SRS 全部 health。
- [ ] 预置短 MP4、待审稿件、两个演示用户、直播房间和可举报内容。
- [ ] 设定 1920×1080 或 1280×720，麦克风采样正常，鼠标可见。
- [ ] 先录 15 秒测试片，确认中文、终端和 Network 字体可读。

## 建议时间线（目标 6:30–7:30）

| 时间 | 画面 | 必须说清 |
| --- | --- | --- |
| 0:00–0:35 | PPT 封面与架构 | 单体基线、Gateway、四 owner 服务 |
| 0:35–1:20 | 登录、资料、推荐 | UC01/02 与 requestId/upstream |
| 1:20–2:20 | 上传、提审、审核发布 | content/governance 边界与幂等 |
| 2:20–3:00 | 评论、点赞、通知 | 事务主体 + Outbox |
| 3:00–4:20 | 开播、消息、投币、录播 | SRS、持久化、账本、replay |
| 4:20–5:00 | 举报与处置 | 状态应用、不可重复处理、审计 |
| 5:00–6:20 | REG/CI/HPA/故障/性能 | 12/12、3/3、1→3→1、恢复、0 error |
| 6:20–7:00 | rollback 与总结 | 能力白名单、单体表保留、可恢复证据链 |

## 录制后验收

- [ ] 总时长在 5–8 分钟。
- [ ] 画面无黑屏、卡帧、严重压缩或不可读文字。
- [ ] 人声清晰、无持续底噪，音画同步。
- [ ] 六个 UC 都有画面或明确说明为何使用预置结果。
- [ ] 至少展示一个运行时 health/version/requestId，不是全程 PPT。
- [ ] CI/HPA/故障/性能数字与仓库最终文档一致。
- [ ] 没有显示 Secret、Token、私人账号、聊天或个人联系方式。
- [ ] 从头到尾完整播放一次，记录复核人和时间。
- [ ] 上传到课程允许的位置，并用另一账号/无痕窗口验证权限。
- [ ] 记录文件 SHA-256，避免提交后无法确认版本。
