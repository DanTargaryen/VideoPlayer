# 观澜视频平台用例场景清单

本文档根据《软件需求说明书(1)》中的核心用例追踪关系，以及《软件详细设计说明书》中回归用例的表达方式整理，用于概括观澜视频平台的主要使用场景和核心业务闭环。

## 1. 场景总览

观澜视频平台的主要用例可以归纳为 8 类：

| 编号 | 场景名称 | 主要参与角色 | 说明 |
| --- | --- | --- | --- |
| SC-01 | 内容浏览与发现 | 游客、普通用户 | 浏览首页推荐、分区内容、热门榜单、关注流与用户主页。 |
| SC-02 | 全局搜索与结果筛选 | 游客、普通用户 | 搜索视频、用户和直播，查看热词、联想词和结果分栏。 |
| SC-03 | 视频观看与互动 | 普通用户 | 播放视频、点赞、收藏、评论、回复、弹幕和关注作者。 |
| SC-04 | 创作者投稿与稿件管理 | 创作者、普通用户 | 创建草稿、上传媒体、编辑信息、提交审核、撤回和重提。 |
| SC-05 | 管理员审核与治理 | 管理员 | 审核视频、处理评论和弹幕文本、处置举报记录。 |
| SC-06 | 直播开播与观看 | 主播、观众 | 创建直播间、开播、观看、聊天、结束直播并保存回放。 |
| SC-07 | AI 辅助与智能回复 | 普通用户、创作者 | 生成视频摘要、进行视频问答、触发评论区 `@grok` 回复。 |

## 3. 核心场景说明

### 3.1 内容浏览与发现

该场景面向游客和普通用户，重点覆盖首页推荐、分区浏览、热门内容、关注流和用户主页访问。它是平台最基础的入口场景，也是后续搜索、观看和互动的前置路径。

### 3.2 视频观看与互动

这是平台的主使用场景之一。用户从列表进入视频详情页后，可以完成播放、暂停、倍速、弹幕、评论、回复、点赞、收藏、投币和关注等动作。互动行为会影响推荐规则和用户画像。

### 3.3 投稿与审核闭环

创作者先创建草稿并补充媒体、标题、简介、分区、封面等信息，再提交审核。管理员审核通过后，视频才进入公开分发。若被驳回，创作者修改后可再次提交，形成完整闭环。

### 3.4 直播与回放

主播创建直播间后开启直播，观众进入观看并参与聊天互动。直播结束后，系统保存会话状态和回放资源，供后续继续访问或复盘。

### 3.5 智能辅助与治理

平台提供视频摘要、视频问答和评论区 AI 回复能力，同时具备举报处理、文本审核和后台治理能力，用于提升内容可读性和平台秩序。

2. 直播、AI 和审核治理相关能力在课程演示语境下依赖外部服务或 mock 实现，实际交付时需结合部署文档与接口清单一起验证。
