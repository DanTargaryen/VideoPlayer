# 观澜视频平台用户手册

## 1. 手册说明

本文档面向“观澜视频平台”的普通用户、创作者、主播和管理员，说明网站主要功能的使用方法、入口位置和常见问题处理方式。

平台支持以下核心功能：

- 浏览推荐视频和分区内容
- 搜索视频、用户和直播
- 播放视频、发送弹幕、评论、点赞、收藏、投币
- 投稿视频并提交审核
- 管理个人作品、收藏夹、观看记录和账号资料
- 开启直播、观看直播、发送直播弹幕
- 发布动态、互动评论、查看关注流
- 私信聊天和消息通知
- 管理员审核视频、评论、弹幕和举报内容

## 2. 访问入口

本地开发环境默认访问地址：

```text
http://localhost:5173/
```

局域网演示环境通常使用启动脚本输出的 HTTPS 地址，例如：

```text
https://10.124.244.156:5173/
```

如果需要使用摄像头、麦克风或屏幕共享，请使用 `localhost` 或 HTTPS 地址访问。浏览器会限制非安全来源下的媒体采集能力。

## 3. 用户角色说明

| 角色 | 说明 | 主要能力 |
| --- | --- | --- |
| 游客 | 未登录用户 | 浏览首页、搜索、观看公开视频、查看公开用户主页 |
| 普通用户 | 已注册并登录的用户 | 评论、弹幕、点赞、收藏、投币、投稿、直播、发动态、私信 |
| 创作者 | 普通用户的一种使用身份 | 上传视频、编辑稿件、提交审核、管理作品 |
| 主播 | 普通用户的一种使用身份 | 创建直播间、开启直播、发送直播弹幕、保存直播回放 |
| 管理员 | 审核与管理用户 | 审核视频、处理文本内容、处理举报、查看后台数据 |

## 4. 首页使用

### 4.1 进入首页

打开网站后默认进入首页，也可以点击左上角站点 Logo 返回首页。

首页主要区域包括：

- 顶部导航栏
- 搜索框
- 推荐内容
- 分区入口
- 视频卡片列表

### 4.2 浏览推荐视频

在首页推荐区浏览视频卡片。视频卡片通常包含：

- 视频封面
- 标题
- UP 主或创作者信息
- 播放量、点赞量、评论量等基础数据

点击视频卡片进入视频详情页。

### 4.3 进入内容分区

顶部或首页分区入口可进入不同内容分类，例如：

- 娱乐
- 学习
- 游戏
- 科技
- 动画
- 生活
- 音乐
- 影视
- 运动
- 搞笑
- 美食
- 旅行

分区页会展示对应分类下的视频内容。

## 5. 登录与注册

### 5.1 注册账号

操作步骤：

1. 点击右上角“登录”。
2. 在登录页点击“注册”。
3. 输入用户名、密码和昵称等信息。
4. 点击“注册”。
5. 注册成功后系统会自动登录或跳转到登录状态页面。

注意事项：

- 用户名应保持唯一。
- 密码长度需满足系统校验要求。
- 注册失败时，按页面提示修改输入内容后重试。

### 5.2 用户登录

操作步骤：

1. 点击右上角“登录”。
2. 输入用户名或邮箱。
3. 输入密码。
4. 点击“登录”。

登录成功后，顶部会显示用户入口。需要登录的页面会在未登录时自动跳转到登录页，登录后再回到原页面。

### 5.3 管理员登录

管理员入口在登录页中切换：

1. 进入登录页。
2. 点击“管理入口”。
3. 输入管理员密钥或管理员登录信息。
4. 登录成功后进入审核后台。

普通用户无法访问管理员后台。

### 5.4 退出登录

操作步骤：

1. 点击右上角头像或用户入口。
2. 进入个人中心。
3. 在账号设置区域点击“退出登录”。

退出后需要重新登录才能使用投稿、评论、直播、消息等功能。

## 6. 搜索功能

### 6.1 发起搜索

操作步骤：

1. 在顶部搜索框输入关键词。
2. 按回车或点击搜索按钮。
3. 进入搜索结果页。

搜索支持：

- 视频标题与描述
- 用户昵称或账号
- 直播内容
- 相关关键词

### 6.2 筛选搜索结果

搜索页通常支持按类型查看：

- 视频
- 用户
- 直播

可根据页面提供的筛选项进一步筛选分区、排序方式或内容类型。

### 6.3 进入搜索结果

点击视频结果进入视频详情页。

点击用户结果进入用户主页。

点击直播结果进入直播间。

## 7. 视频观看与互动

### 7.1 播放视频

操作步骤：

1. 从首页、分区页或搜索页点击视频卡片。
2. 进入视频详情页。
3. 使用播放器控制播放、暂停、进度、音量和全屏。

如果视频无法播放，请检查网络、视频资源地址或后端服务状态。

### 7.2 发送视频弹幕

操作步骤：

1. 登录用户账号。
2. 进入视频详情页。
3. 播放视频到希望发送弹幕的时间点。
4. 在播放器下方弹幕输入框输入内容。
5. 点击“发送”或按回车。

弹幕发送成功后会立即显示在播放器上方，并记录在该视频对应时间点。

注意事项：

- 弹幕内容不能为空。
- 未登录时无法发送弹幕。
- 弹幕内容违规时可能被隐藏或被管理员处理。

### 7.3 开关弹幕

在播放器下方找到弹幕开关。关闭后，弹幕不会在播放器上显示；再次开启后，弹幕恢复显示。

### 7.4 举报弹幕

操作步骤：

1. 在弹幕上点击或悬停打开操作菜单。
2. 点击“举报”。
3. 填写或选择举报原因。
4. 提交举报。

举报会进入管理员处理流程。

### 7.5 点赞视频

操作步骤：

1. 登录用户账号。
2. 进入视频详情页。
3. 点击点赞按钮。

再次点击可取消点赞。

### 7.6 收藏视频

操作步骤：

1. 登录用户账号。
2. 进入视频详情页。
3. 点击收藏按钮。
4. 选择收藏夹。
5. 点击确认收藏。

收藏后可在个人中心的收藏夹中查看。

### 7.7 投币

操作步骤：

1. 登录用户账号。
2. 进入视频详情页。
3. 点击投币按钮。
4. 确认投币数量。

投币需要账户有足够礼物币或可用余额。单个视频可能存在投币上限。

### 7.8 评论视频

操作步骤：

1. 登录用户账号。
2. 进入视频详情页。
3. 滚动到评论区。
4. 输入评论内容。
5. 可选：上传评论图片。
6. 点击“发表评论”。

评论成功后会显示在评论区。

### 7.9 回复评论

操作步骤：

1. 在评论区找到目标评论。
2. 点击回复入口。
3. 输入回复内容。
4. 提交回复。

### 7.10 撤回评论

用户可撤回自己发布的评论：

1. 找到自己发布的评论。
2. 点击撤回或删除操作。
3. 确认撤回。

撤回后该评论及相关回复可能不可恢复。

### 7.11 视频智能体

视频详情页提供智能体相关能力。用户可以围绕视频内容提问，或在评论中使用 `@grok` 触发智能回复。

使用建议：

- 问题尽量具体。
- 如果智能回复仍在生成中，可稍后刷新评论。
- 智能体回答仅用于辅助理解，不代表平台最终结论。

## 8. 投稿与稿件管理

### 8.1 进入投稿页

操作步骤：

1. 登录用户账号。
2. 点击顶部“上传”或“投稿”入口。
3. 进入投稿页。

未登录时会先跳转到登录页。

### 8.2 创建稿件

投稿页可填写：

- 视频文件
- 视频标题
- 视频简介
- 内容分区
- 标签
- 封面图片

操作步骤：

1. 选择本地视频文件。
2. 填写标题和简介。
3. 选择视频分区。
4. 可选：上传封面。
5. 点击“创建稿件”。

创建成功后，稿件会进入个人中心的作品列表。

### 8.3 编辑稿件

操作步骤：

1. 进入个人中心。
2. 找到“我的作品”。
3. 选择需要编辑的稿件。
4. 修改标题、简介、分区、封面等信息。
5. 保存修改。

如果稿件已被驳回，可修改后重新提交审核。

### 8.4 提交审核

操作步骤：

1. 进入个人中心的“我的作品”。
2. 找到草稿或可重新提交的稿件。
3. 点击“提交审核”。
4. 等待管理员审核。

审核状态包括：

- 草稿
- 待审核
- 审核中
- 已通过
- 已驳回

审核通过后，视频可在站内被其他用户浏览。

### 8.5 查看审核记录

操作步骤：

1. 进入个人中心。
2. 在作品列表中找到目标稿件。
3. 点击“审核记录”。

审核记录会展示审核结果和审核意见。

### 8.6 撤回审核

如果稿件处于可撤回状态，可在作品列表中点击“撤回审核”。撤回后稿件回到草稿或可编辑状态。

### 8.7 删除稿件

操作步骤：

1. 进入个人中心。
2. 找到目标稿件。
3. 点击删除。
4. 确认删除。

删除后，该视频相关的播放、评论、弹幕、点赞与收藏数据也可能被移除，且不可恢复。

## 9. 个人中心

### 9.1 进入个人中心

登录后点击右上角头像或用户入口，进入个人中心。

个人中心包含：

- 我的作品
- 我的收藏
- 收藏夹管理
- 点赞记录
- 观看历史
- 账号资料
- 账号安全

### 9.2 管理收藏夹

操作步骤：

1. 进入个人中心。
2. 打开“我的收藏夹”。
3. 输入收藏夹名称。
4. 点击创建。

收藏夹可用于分类管理收藏的视频。

删除收藏夹时，其中的视频通常会移动到默认收藏夹或按系统规则处理。

### 9.3 查看收藏视频

操作步骤：

1. 进入个人中心。
2. 选择收藏夹。
3. 查看当前收藏夹中的视频。
4. 可使用搜索框在收藏夹内搜索。

### 9.4 修改账号资料

操作步骤：

1. 进入个人中心。
2. 打开账号资料区域。
3. 修改昵称、头像、简介或邮箱等信息。
4. 保存修改。

### 9.5 删除账号

账号删除属于高风险操作。删除账号可能同时删除：

- 用户资料
- 投稿视频
- 评论和回复
- 弹幕
- 收藏、点赞、关注等互动数据

操作前请确认不再需要相关数据。

## 10. 直播功能

### 10.1 进入直播中心

点击顶部导航栏“直播”进入直播页面。

直播页面包含：

- 直播广场
- 热门直播
- 我的直播工作台
- 直播设置
- 直播间观看区域
- 直播弹幕互动区

### 10.2 观看直播

操作步骤：

1. 进入直播页。
2. 在直播广场或热门直播中选择直播间。
3. 点击进入直播间。
4. 点击“进入观看”或等待自动接入。

系统会优先尝试 RTC 观看链路。如果 RTC 不可用，会自动切换到兼容画面模式。

### 10.3 发送直播弹幕

操作步骤：

1. 登录用户账号。
2. 进入直播间。
3. 在右侧“弹幕互动”输入框输入内容。
4. 点击“发送”或按回车。

直播弹幕会显示在右侧消息列表，并在直播画面上飞屏展示。

### 10.4 创建直播

操作步骤：

1. 登录普通用户账号。
2. 进入“直播”页面。
3. 在“我的直播工作台”填写直播标题。
4. 选择直播分类。
5. 选择直播方式：
   - 摄像头直播
   - 屏幕共享直播
6. 可选：上传直播封面。
7. 点击准备预览。
8. 浏览器弹出权限时，允许摄像头、麦克风或屏幕共享。
9. 预览正常后点击“开始直播”。

### 10.5 结束直播

操作步骤：

1. 在直播工作台点击“结束直播”。
2. 系统停止推流。
3. 如果存在录制内容，可选择保存为稿件或下载到本地。

### 10.6 保存直播回放

直播结束后，如果系统生成录制内容，可执行：

1. 点击“保存为稿件”。
2. 填写回放标题、简介和封面。
3. 提交保存。

保存成功后，回放会作为视频稿件进入个人中心，可继续编辑和提交审核。

### 10.7 离开直播间

观众模式下点击“离开直播”，系统会断开观看连接并返回直播页面。

## 11. 动态功能

### 11.1 进入动态页

点击顶部导航栏“动态”进入动态页面。当前路由会进入通知/动态聚合页面。

动态页可以查看：

- 关注用户更新
- 视频投稿动态
- 直播动态
- 文本动态
- 推荐用户
- 正在直播的创作者

### 11.2 发布动态

操作步骤：

1. 登录用户账号。
2. 进入动态页。
3. 在动态编辑框输入内容。
4. 可根据页面支持添加图片、话题或关联内容。
5. 点击发布。

### 11.3 动态互动

可对动态执行：

- 点赞
- 评论
- 收藏
- 进入关联视频或直播
- 进入发布者主页

未登录用户需要先登录后才能互动。

## 12. 消息中心

### 12.1 进入消息中心

登录后点击顶部右侧“消息”进入消息中心。

消息中心包含：

- 会话列表
- 聊天记录
- 私信输入框
- 未读消息提醒

### 12.2 发送私信

操作步骤：

1. 进入消息中心。
2. 在左侧选择会话联系人。
3. 在右侧输入消息内容。
4. 点击发送。

也可以从用户主页进入私信会话。

### 12.3 查看未读消息

顶部消息入口或消息中心会提示未读消息。进入会话后，系统会按页面逻辑更新已读状态。

## 13. 用户主页

### 13.1 进入用户主页

可通过以下入口进入用户主页：

- 点击视频作者头像或昵称
- 点击评论用户头像或昵称
- 点击搜索结果中的用户
- 点击动态中的用户信息

### 13.2 查看用户内容

用户主页通常展示：

- 用户昵称和头像
- 个人简介
- 投稿视频
- 互动数据
- 关注或私信入口

### 13.3 关注用户

登录后可在用户主页点击关注。再次点击可取消关注。

## 14. 通知功能

通知页用于展示系统消息、互动提醒或关注更新。登录后可查看通知列表，并根据页面操作进入相关视频、动态、用户或直播内容。

常见通知包括：

- 评论或回复提醒
- 点赞收藏提醒
- 审核状态变化
- 系统消息
- 关注用户动态

## 15. 管理员后台

### 15.1 进入后台

操作步骤：

1. 进入登录页。
2. 切换到管理入口。
3. 输入管理员密钥或管理员账号信息。
4. 登录后进入管理员后台。

普通用户无法访问后台页面。

### 15.2 审核视频

管理员可在后台查看待审核视频。

操作步骤：

1. 打开“视频审核”列表。
2. 查看视频标题、简介、封面、上传者和状态。
3. 点击审核操作。
4. 选择通过或驳回。
5. 驳回时填写审核意见。

审核通过后，视频可被普通用户浏览。

### 15.3 处理评论和弹幕

管理员可处理风险文本内容，包括：

- 评论
- 回复
- 弹幕

处理方式通常包括：

- 保持正常
- 隐藏内容
- 删除或标记违规

### 15.4 处理举报

用户提交的视频、评论或弹幕举报会进入后台。

操作步骤：

1. 打开举报列表。
2. 查看举报对象和原因。
3. 判断是否违规。
4. 选择处理结果。

### 15.5 查看后台概览

后台概览可查看平台运营指标，例如：

- 待审核视频数量
- 举报数量
- 异常评论数量
- 异常弹幕数量
- 用户和内容统计

## 16. 常见问题

### 16.1 无法登录

可检查：

1. 用户名或邮箱是否正确。
2. 密码是否正确。
3. 后端服务是否正常。
4. 数据库是否可连接。

如果忘记密码，可使用登录页提供的重置密码能力。

### 16.2 投稿失败

常见原因：

1. 未登录。
2. 视频文件格式不支持。
3. 文件过大或上传超时。
4. MinIO 对象存储不可用。
5. 后端服务不可用。

处理建议：

- 重新登录后再试。
- 换一个较小的视频文件测试。
- 检查后端和 MinIO 是否运行。

### 16.3 视频无法播放

可检查：

1. 视频是否审核通过。
2. 视频资源是否存在。
3. MinIO 或媒体代理是否可访问。
4. 浏览器控制台是否存在 mixed content 错误。
5. 网络连接是否正常。

### 16.4 弹幕或评论发送失败

常见原因：

1. 未登录或登录状态过期。
2. 后端服务异常。
3. 内容为空。
4. 内容被风控或审核规则拦截。

处理建议：

- 刷新页面。
- 重新登录。
- 缩短内容后重试。
- 检查后端健康状态。

### 16.5 直播无法开播

常见原因：

1. 未登录。
2. 浏览器未授权摄像头、麦克风或屏幕共享。
3. 使用了非安全来源地址，例如 `http://局域网IP:5173`。
4. SRS 服务不可用。
5. 防火墙阻止直播端口。

处理建议：

- 本机使用 `http://localhost:5173/`。
- 局域网使用 `https://<LAN-IP>:5173/`。
- 浏览器权限弹窗选择允许。
- 检查 SRS 服务是否启动。

### 16.6 直播有画面延迟

如果 RTC 链路不可用，系统会退回兼容帧模式。兼容帧模式通过连续图片刷新模拟直播画面，延迟和流畅度不如 RTC，属于正常现象。

### 16.7 局域网其他电脑无法访问

可检查：

1. 是否使用 `npm run dev:lan` 启动。
2. 是否访问脚本输出的 HTTPS 地址。
3. 当前 IP 是否正确。
4. 防火墙是否放通端口。
5. 浏览器是否接受本地开发证书。

## 17. 使用建议

- 投稿前先准备清晰标题、简介、分区和封面。
- 评论和弹幕请遵守平台规则，避免发布攻击、广告或违法内容。
- 直播前先测试摄像头、麦克风和屏幕共享权限。
- 管理员审核时应根据平台规则填写明确审核意见。
- 如果页面状态异常，优先刷新页面或重新登录。
