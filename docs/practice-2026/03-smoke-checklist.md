- 主成功流程：**PASS**。使用隔离普通账号登录，修改昵称后刷新页面仍保持；清除浏览器会话并重新登录后资料仍保持。
- 异常流程：**PASS**。错误密码返回 401 且不创建 token；普通用户访问管理员页面被重定向到登录页，调用管理员接口返回 401 `Admin required`。
- 最终结果：**PASS**。

## 4. UC02 视频发现、播放与观看记录

- 主成功流程：**PASS**。首页推荐返回已发布视频；视频详情加载并从 0 秒播放超过 14 秒；播放和观看进度接口成功，用户中心可查观看历史；待审核视频不能从公共入口访问。

- 最终结果：**FAIL**。

- [x] 首页推荐、分区或搜索至少一条入口返回已发布视频。

## 7. UC05 直播、互动、礼物与录播回看

- 主成功流程：**PASS**。主播准备本地模拟摄像头/麦克风并开播，观众从直播入口进入兼容帧模式；双方消息互相可见；两次投币后余额从 10 变为 8，数据库有两条合计 -2 的交易，第三次超过单视频上限返回 400 且余额不再减少；结束后房间为 `ENDED` 并成功登记回放稿件。
- 异常流程：**FAIL**。回放对象已登记但浏览器报告格式错误、无法播放；隔离 SRS 停止时发布接口返回 400 `SRS service is unavailable`，恢复容器后健康接口恢复。后端重启后，内存房间和会话按当前实现返回 404，已登记稿件仍保留在数据库。
- 最终结果：**FAIL**。

- [x] 聊天或互动消息可被双方观察。

## 9. 缺陷记录

### BUG-BASE01-UC02-01

- 缺陷编号：`BUG-BASE01-UC02-01`
- 复现步骤：普通用户登录；在全局搜索框输入 `BASE01-不存在的视频-UC02`；执行搜索并查看视频结果。
- 期望结果：视频结果为 0，并显示明确的无结果提示。
- 实际结果：接口返回 200 且 `counts.video=2`，页面展示两条与关键词无关的已发布视频。

### BUG-BASE01-UC02-02

- 缺陷编号：`BUG-BASE01-UC02-02`
- 复现步骤：普通用户打开已发布视频详情；使该视频的媒体清单请求返回 503；点击播放器并观察播放区。
- 期望结果：页面显示媒体暂不可用或加载失败的明确状态，其他详情内容保持可用。
- 实际结果：详情页仍在，但播放器只显示 `00:00 / 00:00`，没有错误说明。

### BUG-BASE01-UC03-01

- 缺陷编号：`BUG-BASE01-UC03-01`
- 复现步骤：普通创作者进入投稿页；标题填写 `BASE01-UC03-INVALID`；选择一个内容为纯文本的 `.txt` 文件作为视频；提交创建。
- 期望结果：前端或后端拒绝无效媒体并显示明确错误，不创建稿件和存储对象。
- 实际结果：对象上传接口和稿件创建接口均返回 201，页面跳转到用户中心并出现一个 0 秒草稿，隔离 MinIO 中存在该文本对象。

### BUG-BASE01-UC05-01

- 缺陷编号：`BUG-BASE01-UC05-01`
- 复现步骤：主播使用摄像头模式开始直播；结束直播；在“保存直播内容”对话框选择“保存为稿件”；观众刷新已结束的直播间并播放回放。
- 期望结果：回放对象以浏览器支持的媒体类型返回，观众可在直播间播放已登记回放。
- 实际结果：保存接口成功、房间得到回放 URL 且创建视频稿件；对象响应 `Content-Type: text/plain`，浏览器报告 `MEDIA_ELEMENT_ERROR: Format error`，回放无法播放。

### BUG-BASE01-UC06-01

- 缺陷编号：`BUG-BASE01-UC06-01`
- 复现步骤：普通用户对同一已发布视频提交一次举报；使用相同账号、相同目标和相同原因再次提交举报；查看管理员举报列表或数据库记录。
- 期望结果：第二次提交被幂等处理或明确拒绝，不新增重复待处理记录。
- 实际结果：两次请求均返回 201，并创建两条不同编号、状态均为 `PENDING` 的举报记录。
