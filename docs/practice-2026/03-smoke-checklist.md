## 3. UC01 账户访问与资料维护

- [ ] 注册或选用隔离测试账号。
- [ ] 正确验证码/账号登录成功。
- [ ] 修改资料并在刷新/重新登录后保持。
- [ ] 普通用户访问管理员接口被拒绝。
- [ ] 错误密码或验证码返回明确错误且不创建会话。
- [ ] 保存请求/响应、页面结果和后端日志证据。

## 4. UC02 视频发现、播放与观看记录

- [ ] 首页推荐、分区或搜索至少一条入口返回已发布视频。
- [ ] 搜索条件和无结果提示正确。
- [ ] 视频详情可加载并播放媒体。
- [ ] 未发布/驳回视频不能从公共入口访问。
- [ ] 已登录用户播放后，观看历史可查。
- [ ] 媒体 URL 失败时页面有可解释状态，不白屏。

## 5. UC03 投稿、媒体处理、审核与发布

- [ ] 创作者上传隔离测试视频和封面。
- [ ] MinIO 中对象和数据库 `VideoAsset`/视频记录可对应。
- [ ] 时长、封面或转码结果至少验证课程演示范围内的一项媒体处理。
- [ ] 提交审核后，公共入口不可见。
- [ ] 管理员通过后可搜索/播放。
- [ ] 管理员驳回时原因可见，创作者可修改或重提。
- [ ] 模拟一次无效文件或上传失败，状态和提示正确。
- [ ] 测试数据使用明显前缀，可在验证后清理或重置 seed。

## 6. UC04 视频互动、关注与通知

- [ ] 用户可点赞并取消，计数与关系一致。
- [ ] 用户可收藏到默认/指定收藏夹并取消。
- [ ] 用户可评论或回复，创作者/被回复者收到通知。
- [ ] 用户可发送视频弹幕并重新加载查看。
- [ ] 用户可关注创作者，关注流或主页状态更新。
- [ ] 重复操作、游客操作和目标已删除时结果可解释。

## 7. UC05 直播、互动、礼物与录播回看

- [ ] 主播创建直播间并开始直播。
- [ ] 观众从直播入口进入并看到播放/兼容帧。
- [ ] 聊天或互动消息可被双方观察。
- [ ] 礼物/币操作余额和记录一致，不重复扣款。
- [ ] 主播结束直播，房间状态可查询。
- [ ] 录播可保存、登记和回看（如教师确认计入）。
- [ ] 重启后房间状态的预期行为已明确并验证。
- [ ] SRS/录播失败时有设计好的提示或恢复路径。

## 8. UC06 举报、审核与治理处置

- [ ] 用户举报视频、评论或弹幕中的至少一种目标。
- [ ] 管理员可在后台查到待处理举报。
- [ ] 通过处置后目标状态按规则变化，处理人/时间/原因可查。
- [ ] 驳回举报后目标保持原状态，举报状态正确。
- [ ] 普通用户调用管理员接口被拒绝。
- [ ] 目标不存在、重复举报或依赖失败时结果可解释。

## 9. 基线标签 Gate

只有以下全部满足，组长才能创建 `monolith-start`：

- [ ] 教师/助教已确认最终业务场景范围。
- [ ] 确认范围内所有用例结果为 `PASS`，或有明确的书面排除确认。
- [ ] 前端和后端生产构建通过。
- [ ] README 启动步骤已由另一名组员从头复现。
- [ ] 工作树和暂存区干净。
- [ ] smoke 结果、commit 和日志路径已归档。
- [ ] 使用 annotated tag，且全组确认标签不可移动。
