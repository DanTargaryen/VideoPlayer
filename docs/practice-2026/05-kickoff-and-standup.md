## 4. 每日 5 分钟站会

每个人只回答三件事：

1. 昨天完成了什么？附任务 ID 和证据。
2. 今天唯一主目标是什么？写到可在当天验证。
3. 现在卡在哪里？谁在什么时候解除阻塞？

### 个人记录模板

```text
姓名：
日期：
昨天：完成 [任务 ID]，结果/证据：
今天：完成 [任务 ID] 的 [可验证目标]：
阻塞：
需要谁在何时协助：
风险变化：
```
