# 启动会与每日站会模板

## 1. 60 分钟启动会议程

| 时间 | 议题 | 必须输出 |
| --- | --- | --- |
| 0-10 分 | 对齐评分与原则 | 前 5 天 40 分优先；不扩大 UC；不先拆服务 |
| 10-20 分 | 审阅 UC01-UC06 | 修改意见、教师确认问题、需排除功能 |

| 40-50 分 | 导入任务包 | 19 张首轮任务卡、截止、DoD、证据 |
| 50-60 分 | 确认 D1 Gate | 全 UC smoke、教师确认、基线标签、测试/容器骨架 |

## 4. 每日 5 分钟站会

每个人只回答三件事：

1. 昨天完成了什么？附任务 ID 和证据。
2. 今天唯一主目标是什么？写到可在当天验证。
3. 现在卡在哪里？谁在什么时候解除阻塞？

### 个人记录模板

```text
姓名：
日期：
昨天：完成 [任务 ID]，结果/证据：
今天：完成 [任务 ID] 的 [可验证目标]：
阻塞：
需要谁在何时协助：
风险变化：
```

### 组长约 200 字简报模板

```text
【第 X 组站会简报｜2026-XX-XX】
昨日：完成……，对应任务……，已有证据……。
今日：A 负责……；B 负责……；C 负责……；D 负责……；E 负责……。
当前阻塞：……，由……在……前处理。
风险：……。
今日 Gate：……；若未达到，止损方案为……。
看板/证据链接：……。
```

## 5. 会议结束检查

- [ ] 每个 P0 任务只有一个主负责人。
- [ ] 每个负责人有 Reviewer 和备份人。
- [ ] 每个人的 D1 目标能在当天验证。
- [ ] Docker/K8s 环境有确定主机和完成时间。
- [ ] 教师确认消息有发送人和截止时间。
- [ ] 次日 9:00 站会和 12:00 简报责任人已确认。
